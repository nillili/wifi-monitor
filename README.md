# 와이파이 감시 (Wi-Fi Monitor)

행사장 와이파이 상태를 실시간으로 보여 주고, 나중에 리포트를 쓸 수 있도록 1분마다 기록을 남기는 프로그램입니다.

AP가 내보내는 신호를 듣기만 하므로 네트워크에 주는 부하는 거의 없습니다.

## 실행

리눅스, 윈도우, 맥에서 돌아갑니다. 파이썬 3.7 이상만 있으면 되고, 추가로 설치할 패키지는 없습니다.

| 운영체제 | 실행 명령 |
|---|---|
| 리눅스 · 맥 | `python3 wifi_monitor.py` |
| 윈도우 | `python wifi_monitor.py` (안 되면 `py wifi_monitor.py`) |

실행한 뒤 브라우저에서 http://127.0.0.1:8840 을 엽니다. 로그인은 없습니다.

끝낼 때는 실행한 터미널(명령 창)에서 `Ctrl + C`를 누릅니다.

리눅스에서 터미널을 닫아도 계속 돌게 하려면 이렇게 실행하고, 끝낼 때는 `pkill -f wifi_monitor.py`를 씁니다.

```bash
setsid nohup python3 -u wifi_monitor.py >> logs/실행기록.txt 2>&1 < /dev/null &
```

## 운영체제별 차이

| 항목 | 리눅스 | 윈도우 | 맥 |
|---|---|---|---|
| 값을 읽는 방법 | `iw`, `nmcli` | `netsh` | `system_profiler` |
| 내 연결 신호·속도 갱신 | 3초 | 3초 | 1분 |
| 신호 값 | 실제 dBm | %를 dBm으로 어림한 값 | 실제 dBm |
| AP 구분 | 주소(MAC) | 주소(MAC) | 이름+채널 (주소를 주지 않음) |
| 공유기 지연 측정 | 3초마다 5번 | 5초마다 3번, 1 ms 단위 | 5초마다 3번 |

- **윈도우 11**: 설정 → 개인 정보 및 보안 → 위치에서 위치 서비스를 켜야 AP 목록이 나옵니다.
- **맥**: 위치 권한이 없으면 와이파이 이름이 가려져 나올 수 있습니다.
- 윈도우와 맥에서는 측정 간격이 길어서, "Last 5 min" 그래프가 실제로는 8분 정도를 보여 줍니다.

## 화면 읽는 법

### My Connection (내 연결)

이 노트북의 연결 상태입니다. 3초마다 바뀝니다.

| 항목 | 뜻 | 적정 값 | 색 표시 |
|---|---|---|---|
| Channel | 지금 붙어 있는 AP의 채널 | - | - |
| Signal | AP 전파의 세기. 0에 가까울수록 강함 | -67 dBm 이상 | -67 미만 노랑, -75 미만 빨강 |
| RX / TX Rate | 노트북과 AP 사이의 무선 연결 속도 (인터넷 속도 아님) | 높을수록 좋음 | - |
| Router Latency | 공유기까지 다녀오는 시간 | 20 ms 미만 | 20 이상 노랑, 50 이상 빨강 |
| Loss | 가다가 사라진 신호의 비율 | 0% | 1% 이상 노랑, 5% 이상 빨강 |
| Internet Latency | 외부 서버(1.1.1.1)까지 연결되는 시간 | 50 ms 미만 | 50 이상 노랑, 100 이상 빨강 |

### AP List (AP 목록)

지금 연결된 와이파이 이름과 같은 이름을 쓰는 AP들입니다. 1분마다 바뀝니다.

- AP 한 대가 2.4GHz와 5GHz 두 줄로 나옵니다.
- 파란 줄이 이 노트북이 붙어 있는 곳입니다.
- **Our APs on Same Channel**: 같은 채널을 쓰는 우리 AP 수. 0이어야 좋고, 1 이상이면 빨강입니다.
- **Other APs on Same Channel**: 같은 채널을 쓰는 남의 AP 수. 적을수록 좋습니다. 정확히 같은 채널 번호만 셉니다.
- AP1~AP4 번호는 주소 순서로 붙인 것이며, 그 시점에 잡힌 AP 수에 따라 번호가 달라질 수 있습니다. 정확한 구분은 Address(주소) 칸으로 합니다.

### Router Latency 그래프

공유기 지연을 보여 주며, 왼쪽 위 탭으로 두 가지를 바꿔 봅니다.

- **Last 5 min (최근 5분)**: 3초마다 잰 값을 실시간으로 보여 줍니다. 아래 눈금은 측정 시각입니다.
- **Today (오늘 전체)**: 아침부터 지금까지를 1분에 한 점으로 줄여서 보여 줍니다. 각 점은 그 1분 중 가장 높았던 값이라, 잠깐 튄 지연도 빠지지 않습니다. 아래 눈금은 1시간 간격입니다.

빨간 세로선은 공유기 응답이 끊긴 순간입니다.

### 상황 메모 (오른쪽 아래)

입력창에 상황을 적고 버튼을 누르거나 Enter를 치면(예: "쉬는 시간") 그래프의 그 시점에 주황색 선과 글씨가 붙고, 로그에도 남습니다. 100자까지 적을 수 있습니다.

### 언어 (왼쪽 아래)

English / 한국어를 고릅니다. 고른 언어는 브라우저에 기억됩니다.

## 로그

`logs/` 폴더에 날짜별 CSV 파일로 쌓입니다. 엑셀에서 바로 열립니다.

| 파일 | 주기 | 내용 |
|---|---|---|
| `연결_날짜.csv` | 1분 | 연결된 AP, 채널, 신호 평균·최저, 속도, 공유기 지연 평균·최대, 손실 평균·최대, 인터넷 지연 평균·최대, 끊김 횟수, 1분 중 가장 높았던 3초 측정값 |
| `AP_날짜.csv` | 1분 | AP별 채널, 신호, 같은 채널의 우리 AP·주변 AP 수, 주소 |
| `메모_날짜.csv` | 입력할 때 | 시각(초 단위)과 상황 메모 |
| `실행기록.txt` | - | 프로그램 실행 메시지와 오류 |

프로그램을 다시 시작해도 로그는 같은 파일에 이어서 쌓입니다. 화면의 그래프와 그래프에 붙은 메모는 다시 시작하면 비워집니다.

## 설정

`wifi_monitor.py` 맨 위에서 바꿉니다.

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 8840 | 화면 주소의 포트 |
| `INTERVAL` | 3 | 측정 간격(초) |
| `RESCAN_EVERY` | 60 | 주변 AP를 다시 찾는 간격(초) |
| `SCAN_WAIT` | 6 | AP 찾기가 끝나기를 기다리는 시간(초) |

## 알아 둘 점

- **AP별 접속자 수는 나오지 않습니다.** AP가 그 값을 신호에 실어 보내지 않기 때문이며, 공유기 관리 프로그램(Omada 컨트롤러)에서 봐야 합니다.
- **이 노트북 한 대의 자리에서 본 값입니다.** 다른 AP에 붙은 사람의 상태는 알 수 없습니다.
- **노트북이 절전에 들어가면 기록이 멈춥니다.** 전원을 연결하고 덮개를 닫지 않습니다.
- 주변 AP를 찾는 6초 동안에는 측정을 쉬므로, 1분에 한 번 화면 갱신이 잠깐 늦어집니다.
- 이 컴퓨터에서만 열립니다(127.0.0.1). 다른 기기에서는 접속할 수 없습니다.
